## Overview

**The Walking Dead** is a post-apocalyptic horror television series based on the comic book series by Robert Kirkman. It premiered on **AMC** in 2010 and became a global phenomenon.

### Key Elements

- **Genre**: Horror, Drama, Post-apocalyptic  
- **Seasons**: 11  
- **Main Characters**:
  - Rick Grimes
  - Daryl Dixon
  - Carol Peletier
  - Negan Smith

### Notable Themes

1. Survival  
2. Morality in chaos  
3. Family and loyalty  
4. Leadership and power
